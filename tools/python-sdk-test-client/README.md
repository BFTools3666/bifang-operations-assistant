# CloudBase 功能验证助手

这是给第一次部署 CloudBase 的普通用户使用的四步图形向导。它会帮助你确认两件事：

1. CloudBase 是否真的收到了程序发出的匿名测试数据；
2. 修改云端更新文件后，软件是否能看到最新版、普通更新和必须更新。

不需要填写密钥、口令或 Token，也不需要理解程序事件、请求结构或版本判断算法。

## 开始前

先按[CloudBase 新手部署文档](../../docs/cloudbase-quickstart.md)准备以下资源：

- 接收测试数据的云函数；
- `/v1/track` 数据接收通道；
- `telemetry_events` 匿名统计数据表；
- 允许应用名单；
- 可在浏览器直接打开的 `windows.json` 更新文件。

然后在仓库根目录准备依赖：

```powershell
npm ci
npm run build --workspace @bifang/telemetry-update-sdk
```

需要 Node.js 20+、Python 3.9+，以及标准 Python 自带的 Tkinter/ttk。

## 启动图形向导

在仓库根目录运行：

```powershell
python .\tools\python-sdk-test-client\gui.py
```

也可以使用 Windows Python Launcher：

```powershell
py -3 .\tools\python-sdk-test-client\gui.py
```

启动只会准备本地检查组件，不会访问网络、发送数据或打开网页。只有明确点击“发送一组
测试数据到 CloudBase”“模拟 10 台设备使用”或“检查有没有新版本”后，才会访问你填写
的地址。

## 四步怎么用

### 第一步：完成云端准备

逐项核对向导中的五项资源。可以直接点击“打开新手部署文档”和“打开 CloudBase 控制台”。
按钮只打开入口，不会替你部署、修改或删除任何云端资源。

### 第二步：填写你的 CloudBase 信息

只填写四项：

- 应用编号：与云函数允许名单中的值相同；
- 当前版本：例如 `1.2.3`；
- 数据接收地址：完整 `https://.../v1/track` 地址；
- 更新文件地址：浏览器能直接打开的完整 `https://.../windows.json` 地址。

地址默认都是空的，不会读取历史输入。只有你主动点击“载入本项目示例”时，仓库的 smoke
示例才会填入输入框；填入本身仍不会联网。

### 第三步：发送测试数据

“发送一组测试数据到 CloudBase”固定覆盖八类匿名样例：安装、启动、功能使用、任务开始、
任务成功、任务失败、更新提示展示和更新按钮点击。确认窗口只出现一次，并会显示目标域名
与将发送的中文清单。

“模拟 10 台设备使用”会创建十次彼此独立的匿名安装与启动，并为每台加入功能使用、任务
开始以及一次成功或失败结果，共计划 50 条；同时分布不同版本、渠道和常见电脑类型。这里
没有用户账号，不是真实账号登录，也不会读取真实电脑信息。程序会在后台控制发送速度，
避免短时间请求过多。

两种模式都只把云端逐条确认已经保存的记录算作成功。发送过程会显示四个阶段；完成后，
页面用中文卡片展示实际成功数。部分失败时，成功项会保留，失败项会分别告诉你下一步检查
什么。

需要核对真实记录时：

1. 点击“复制本次测试查询条件”或“复制本次模拟的筛选条件”；
2. 点击“打开 CloudBase 数据表”；
3. 在控制台依次进入“云开发统一工作台 → 选择环境 → 文档型数据库 → 集合管理 →
   `telemetry_events`（匿名统计数据表）→ 文档列表 → 筛选”；
4. 直接粘贴，不需要看懂或修改复制出的内容。

### 第四步：验证版本更新

修改并重新发布云端 `windows.json` 后，点击“检查有没有新版本”。每次点击都会重新请求
你填写的完整文件地址，不会复用上一次结果。

- 有普通更新：弹窗显示新版本和云端说明，按钮为“立即更新 / 稍后提醒”；
- 当前版本已停止支持：弹窗要求升级，按钮为“立即更新 / 退出软件”；
- 已是最新版：页面显示“你现在已经是最新版”，不弹窗；
- 云端暂停或本机暂未进入分批发布范围：页面显示对应中文说明。

“立即更新”只会打开云端配置的下载页面，不会自动下载或安装。

## 隐私与安全边界

- 测试身份和每条记录编号都是随机值；
- 固定样例不含姓名、账号、邮箱、文件路径、文件内容、浏览记录或凭证；
- 没有密钥、Secret 或 Token 输入框；
- 原始请求、云端响应、内部身份和英文代码字段默认隐藏，只在“高级排错信息”中提供；
- 失败显示在页面内，不会用系统错误框打断操作；
- 本工具不会部署 CloudBase、修改线上资源、查询数据库或充当管理后台。

## 保留的命令行工具

旧命令行入口继续兼容，供熟悉开发流程的维护者使用：

```powershell
python .\tools\python-sdk-test-client\client.py
```

命令行工具的旧确认和调试流程不代表图形向导的默认体验。

## 自动验证

完整检查：

```powershell
npm run check
```

专项检查：

```powershell
npm run build --workspace @bifang/telemetry-update-sdk
node --test .\tests\python-sdk-test-client.test.mjs
python -m unittest discover -s .\tools\python-sdk-test-client\tests -p "test_*.py" -v
```

自动化测试不创建真实窗口、不访问公网、不打开网页，也不会退出测试进程。
