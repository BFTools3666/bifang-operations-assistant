# 第六步：直接构建并运行当前目标制品

本流程涉及客户操作云端时，在当次提示逐项展开[官方页面指引](../assets/console-guides.json)中适用的 domain、routes、logs：给可点击入口、页面内位置、目标字段或操作和完成标志。

第五门禁通过后，默认下一动作是构建和测试，不停在“测试准备”或重复询问是否开始。先核对已有具体授权；第五门禁计划确认或客户已明确要求构建并测试当前目标时，直接复用。客户仅授权保存/预检、明确排除制品操作，或只要求修改 Skill 时不能扩大范围；补足真正缺少的动作授权即可，不重新审批已覆盖的动作。

## 连续执行范围

第五门禁展示计划时，一并明确后续基础制品测试范围：当前项目与版本、目标平台/架构、构建方式、启动本地产物、真实更新检查，以及已选择统计时的真实日活上报和限定只读核验。客户确认整套计划后，第五门禁通过即自动进入本步骤。此前明确排除了制品测试的旧计划不会因规范升级自动获得授权；客户后续要求“直接构建进行 EXE 测试”可作为当前目标的构建、运行及已说明基础联网测试授权。

默认不包括下载或运行更新链接中的目标安装包、签名、安装、上传、推送发布、改云端发布行为或删除数据。这些动作仅按已给出的对应授权执行。平台范围按客户选择；Windows 结果不代表 macOS 验证完成。

## 构建和测试

1. 自动核对项目版本、目标、第五门禁请求和发布事实仍一致，已有通过证据不无故重复请求。发现实质变更时重做受影响检查。读取项目构建配置和本机工具帮助，使用锁文件及对应生产构建；便携版生成可执行文件，不默认创建/安装 MSI 或 NSIS。已有可确认来源和版本的同一制品可以复用。
2. 构建完成后核对实际文件、PE/适用平台架构、版本、大小与 SHA-256，扫描制品是否含本次私有密钥原值。运行时凭据留在既有受限配置目录，不塞进源码或制品；说明已测机器上的运行条件，不声称裸 EXE 在任意电脑均可用。
3. 通过本机 UI 工具启动真实制品，验证普通更新的启动提示、文案、关闭/稍后、手动检查和原业务入口可用；当前发布为普通更新时，不为测试强更而擅自修改服务。强更、异常等已完成的模拟测试与真实服务测试分别标注。
4. 已选统计时，在授权内核对启动前后限定到本应用的只读统计汇总和本地每日状态。检查实际版本/平台、首次日活入库、同一天重新启动后的去重。不得清除生产安装身份或每日占位以制造重复上报，也不得把每日占位存在当作云端接受成功；没有服务端或传输证据就明确未验证。聚合计数不变也不独立证明没有重复请求，应结合本地状态及已通过的去重逻辑证据说明。
5. 正常关闭应用，核对退出。没有下载授权时不点击会访问外部下载地址的按钮；可以根据既有本地验证保留该动作未做真实验收。

已选统计时，复用本次客户填写的 `display_name` 和已有大屏登录会话，读取目标应用的真实 `/dashboard/api/metrics?days=7&app_id=<app_id>`。逐字核对返回的 `appLabels[app_id]` 和页面应用选择器中该 ID 的可见文字。交付写明期望名称、接口实际值、页面实际值及各自状态。返回 ID、缺项或错误中文均记为失败；仅能读接口时页面记为待验证。统计上报、计数和名称分别给出结论。即使当日数据为零也能核对名称。发现差异按[名称修复](shared-function-extension.md#已接入应用的名称修复)处理。

遇到本地构建或实现错误，按已有接入授权修复、做必要回归并继续。遇到锁屏、认证、无法操作的窗口等外部阻碍，完成可独立开展的检查，准确说明剩余项；不伪造截图或用浏览器 mock 代替真实 EXE 通过。构建结果、界面结果、更新服务结果和统计结果分别记录。

## 交付

第六步完成后，在同一条最终回复中主动交付以下内容，不让客户再追问测试结果、大屏地址或登录凭据：

1. **测试结果**：分别列明构建、真实制品 UI、更新检查和所选统计的通过/失败/未验证状态及关键证据；注明本轮平台、架构和版本。模拟测试不能冒充真实服务验收，统计聚合结果不能冒充请求抓包证据。
2. **制品和回执**：给实际制品绝对路径及可点击链接、大小、SHA-256 和私有验收回执链接。Windows 便携版交付实际 EXE；未选平台继续标记待验证。
3. **统计大屏地址**：已接入统计时，给当前客户环境实际部署的大屏完整可点击 URL。依据已核验部署域名和大屏路由获取，不给控制台地址、管理 API 地址、示例域名或让客户自行拼接。若本次包含页面版本管理，交付同一地址和「版本管理」入口，说明持有该后台登录凭据即可管理其全部已接入应用。列明登录、发布入口、第五门禁实际提交和服务端读回各项结果；复用有效回执，缺项注明待验。区分已有部署/路由证据与本轮实际网页登录验证，未做网页登录不得声称登录已通过。
4. **大屏登录凭据**：本流程最终交付包含向当前客户返回其大屏访问 Token。通过受限本地读取方法，从绑定本次客户和环境的 `service-credentials.json` 仅提取 `dashboard.DASHBOARD_ACCESS_TOKEN`，在最终回复中直接给可复制原值，并说明打开上述大屏后填入 Token 登录框。不以文件路径、脱敏值或 SHA-256 摘要代替凭据，不再次询问是否需要提供。

大屏凭据交付是仅限当前客户最终回复的例外，不允许把原值写入 Skill、业务源码、公开文档、示例、测试、日志或 Git，不在 URL 查询参数中携带 Token。不得混用或返回 CAM SecretId/SecretKey、Cookie、版本服务 app_secret、管理密钥或 `CLOUDBASE_METRICS_TOKEN`；不得通用打印整个私有文件。现有域名、路由或登录凭据缺失/绑定不明时，如实标记交付缺项，不编造、跨客户读取或擅自重置；仅接入更新时，大屏和凭据标为不适用，不为交付而另建统计资源。

只有适用基础用例通过才报告本轮基础制品验收通过，交付缺项单独列明；下载/安装升级、跨日真实测试及未选平台不借此标为通过。第六步完成不自动触发 Git 提交、发布、上传或其他云端变更。仅维护本规范时，不读取真实客户凭据，不执行真实业务请求。
