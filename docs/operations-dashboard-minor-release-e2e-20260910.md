## 安装态测试方法

正式产品标识保持不变。为在同一天验证新版本首次启动，在没有对应应用进程占用时，对各自精确的官方配置目录进行可逆备份隔离；由最终 NSIS 安装出的原程序自行建立全新配置和匿名身份，首次上报后用同一配置重启验证去重。测试完成后还原原有配置和业务数据。

鼠标精灵的匿名统计隐私选择由用户在真实窗口中亲自操作，不由自动化改写。测试不得修改当天门禁、匿名身份或现有同意状态。最终普通启动不得依赖仅存在于测试启动器的版本 API 凭据。

暂停等待安装确认时，鼠标的正式数据目录尚未移动；录屏先前的目录隔离已撤销，两份原配置目录逐文件快照一致地恢复，进程数为 0。录屏首次试包曾安装但未启动，不能把当时安装目录里的旧哈希当成最终 `aa4d209` 试包；下一步必须先安装上表最终包再运行。

生产证据只输出应用、版本、平台、架构、SDK、数量与接收时间；不记录匿名安装标识、事件标识、来源 IP 或凭据原值。
